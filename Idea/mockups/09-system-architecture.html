🏗️ How GitHubXRay works under the hood

An asynchronous, multi-agent pipeline that turns a raw repository into a living, interactive onboarding guide.

① Ingest
🔗 Repo Connector
Public URL or authenticated private repo. Nothing leaves your workspace.
📥 Clone & Index
Parses file tree, languages, configs & git history.
📝 Preference Intake
Questionnaire → learner profile & goals.
② Multi-agent analysis · runs asynchronously
🧠 Orchestrator
Schedules agents, resolves dependencies, merges findings into a shared knowledge graph.

③ Synthesize & deliver
🧩 Guide Composer
Assembles lessons in a Learn-style navigator tailored to the learner.
🎨 Interactive Renderer
Live architecture maps, data-flow & schema visualizers.
📦 Standalone Export
Self-contained HTML / CSS / JS you can run locally. No lock-in.
🔗 Repo in→ 📝 Tailor→ 🤖 Agents analyze→ 🧩 Compose guide→ 🎮 Explore & export
